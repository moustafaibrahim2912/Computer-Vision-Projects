# Computer Vision Projects Portfolio

## Overview
This folder contains a collection of computer vision projects covering a wide range of tasks such as face verification, image classification, and other deep learning-based visual applications.

The goal of this repository is to demonstrate practical experience in building computer vision systems using different tools, frameworks, and approaches.

## Projects Included

- Face Verification System  
- Pistachio Image Classification 

Each project is implemented in a separate notebook and focuses on a complete pipeline from data input to final prediction.

## Core Concepts Covered

- Image Preprocessing & Augmentation  
- Feature Extraction & Deep Learning Embeddings  
- Face Detection & Verification  
- Image Classification  
- Similarity Learning  
- Model Evaluation  

## Tools & Frameworks

This repository uses a variety of tools depending on the project:

- Python

### Deep Learning Frameworks:
